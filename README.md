## Employability Project

**Live business project, Team 7 (employer project, 2026).** Sentiment and text analysis of corporate earnings-call transcripts from 2021 to 2025, using shared processed data tables.

**Methods used:**
- Sentiment analysis of prepared remarks, comparing FinBERT with Llama-3.1
- Sentiment analysis of Q&A sections using FinBERT
- Question sentiment and cosine-similarity analysis
- Anomaly detection on Q&A content using Isolation Forest
- Topic and attention analysis using BERTopic
- A retrieval-augmented generation (RAG) system over the transcripts
